# FlowerBiz

Desktop-first customiser for handmade pipe-cleaner bouquets. This pass sets up the app shell: a landing page and an empty three-column editor with a studio 3D preview.

The full specification is in [PROJECT_SPEC.md](./PROJECT_SPEC.md).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) for the landing page and [http://localhost:3000/customise](http://localhost:3000/customise) for the editor.
